# Mental Math App — instructions for AI agents

Personal, offline Android trainer for math fluency (Galaxy S24). Read before working:

- `docs/VISION.md` – goal, success metrics, non-goals
- `docs/RESEARCH.md` – evidence; **no drill without an entry here**
- `docs/CURRICULUM.md` – skill tree, levels, Vedic tricks
- `docs/SPEC.md` – screens, modes, input, gamification, data model
- `docs/TASKS.md` – current status / next steps
- `design/canvas/` – UI mockups source (3 variants; chosen one to be recorded in `docs/DESIGN.md`)

## Rules

- Keep the codebase small. Borrow only small, compatible code with a permissive
  license (MIT/Apache/BSD); record every borrowing in `THIRD_PARTY.md`.
- Don't recreate other apps' characters, art or branding. Original mascot only.
- Tech stack not decided yet (Flutter vs Kotlin/Compose) — see `docs/TASKS.md`.
- Update `docs/TASKS.md` at the end of each session.
